Everything you need to clean up a PDF

One window, a few focused tools. Load a file once and chain them together.

Deskew

Straighten the tilt scanners leave behind, page by page.

Compress

Shrink big scans with adaptive per-page image recompression.

Merge

Combine several PDFs into one, ordered the way you want.

Organize

Reorder, rotate and delete pages with a thumbnail grid.

History

A local log of everything you've processed, with space saved.

Fully local

Runs on your machine. Nothing is uploaded, and the text layer stays searchable.

Your files stay yours

PDF Bench does all processing on your own computer and never connects to the internet. Your source files are never changed, and every output keeps its searchable text layer, so results still work for copy, search and text-extraction pipelines.

Up and running in a minute

No Python, no setup. Just an installer.

Download

Grab PDFBench-Setup.exe from the releases page.

Install

Run it (per-user, no admin). If SmartScreen warns, choose More info then Run anyway.

Open

Launch PDF Bench from the Start Menu and drop in a PDF.
