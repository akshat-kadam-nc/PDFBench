What it is

PDF Bench is a small Windows app for preparing and tidying PDF files. It was built to get scanned book chapters ready for search/AI pipelines, and grew a handful of everyday PDF tools. It runs entirely on your own computer — no accounts, no uploads, no internet required — and it opens as a normal desktop window (not in your web browser).

Tools available today:

ToolWhat it does
DeskewStraightens pages that a scanner tilted.
CompressShrinks file size by re-encoding the page images.
MergeCombines several PDFs into one.
OrganizeReorder, rotate, and delete pages.
HistoryA local log of everything you've processed.
Every tool keeps the PDF's searchable text layer intact, so the output still works for copy/paste, search, and text-extraction pipelines.

Install

  1. Double-click PDFBench-Setup.exe.
  2. Windows may show a blue SmartScreen warning because the app isn't code-signed. Click More info → Run anyway. (This is expected for independent apps.)
  3. The installer runs per-user — no administrator password needed. Optionally tick "Create a desktop shortcut."
  4. Finish, and optionally let it launch straight away.

It installs to %LocalAppData%\Programs\PDFBench, adds a Start Menu entry, and registers an uninstaller. No Python or other software is required.

Launch & quit

Open Start Menu → PDF Bench (or the desktop shortcut). The app opens in its own window. The first launch each time takes about 15–20 seconds while it unpacks — this is normal. Close the window to quit.

The working document

PDF Bench is built around one working document. You load a PDF once; then every tool acts on it and replaces it with the result. That means you can run several operations in a row without re-uploading the file.

The bar at the top of a tool shows the current file name and a breadcrumb of what's been applied (e.g. deskew → compress). Use Download to save the current result, or Load new to start over with a different file.

Deskew

Straightens the small, consistent tilt an automatic-feed scanner introduces (odd pages lean one way, even pages the other).

  • Deskew mode — Hybrid (default) measures each page and falls back to a fixed angle if the measurement looks wrong; Auto trusts the measurement; Fixed always applies the set angle.
  • Direction — which way odd vs. even pages should rotate.

After running, a per-page table shows the measured and applied angle so you can trust a large batch at a glance. Deskew is lossless — the page image is rotated, not re-encoded.

Compress

Reduces file size by downsampling and re-encoding each page's image.

  • Resolution (DPI) — lower means smaller files (110 is a good default).
  • Color / Gray quality — JPEG quality for color and grayscale pages.
  • Color handling — keep every page in color, decide per page automatically, or force grayscale.

Running several operations at once

Each operation tab (Deskew, Compress) has a checkbox. Tick every operation you want and press Run — they apply in order to the working file in one shot (the button reads e.g. "Run Deskew + Compress"). Click a tab's name to edit that operation's options; the checkbox controls whether it runs.

Merge

Drop in several PDFs, reorder them (they auto-sort by filename), and combine them into one file. The merged result becomes your working document, so you can then Compress or Organize it without re-uploading. Merging is lossless.

Organize pages

Shows a thumbnail of every page. You can:

  • Reorder — drag a page to a new position.
  • Rotate — use the rotate buttons on a page.
  • Delete — remove a page.
  • Bulk actions — click pages to select them, then use Left / Right / Delete at the top.

Press Apply changes to rebuild the PDF. This is lossless and keeps the text layer.

Preview

The right-hand panel shows the current working document. It updates after each operation, and it does not reload when you switch tabs.

History

The History route (top-right) lists every file you've processed, with totals (files, input vs. output size, space saved). Use Clear log to reset it. The log is stored locally on your machine.

Light / dark mode

Use the sun/moon button in the top-right to switch themes. PDF Bench follows your Windows light/dark setting by default and remembers your choice.

Privacy & where files are stored

  • Nothing leaves your computer. All processing happens locally; the app does not connect to the internet.
  • Your source PDFs are never modified — you always get a new file when you Download.
  • The usage log lives at %LocalAppData%\PDFBench\history.jsonl.

Troubleshooting

SymptomFix
SmartScreen blocks the installerClick More info → Run anyway. The app is unsigned but safe.
First launch is slowNormal — the bundle unpacks on each start (~15–20s).
Window is blank / won't displayPDF Bench needs the Microsoft Edge WebView2 Runtime, which is preinstalled on current Windows 10/11. If missing, install it free from Microsoft, then relaunch.
A large file won't processThere's an 80 MB per-file limit. Split very large books into chapters, or lower the DPI.
Download didn't promptDownloads save through the window's built-in viewer; check your Downloads folder.

Uninstall

Use Windows Settings → Apps → PDF Bench → Uninstall, or the "Uninstall PDF Bench" Start Menu shortcut. Your history log is left in place; delete %LocalAppData%\PDFBench if you want it gone too.
